# Target Tasks

Task packets translate a confirmed product decision and target capability into
implementation work for one repository. They do not replace the owning product
journey, backend contract, or target capability.

- [Full Manager Operations Implementation](icebot-webapp/MANAGER_OPERATIONS_FULL_IMPLEMENTATION.md)

## Completion Rule

A task remains incomplete until its target repository contains the required UI,
integration, failure-state, authorization, and verification evidence. Updating
this folder alone does not change the capability status in `targets/*/STATUS.yaml`.
